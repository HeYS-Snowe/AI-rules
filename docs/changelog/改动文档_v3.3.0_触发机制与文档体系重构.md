## Bug 修复

### 1. AGENTS.md 引用不存在的模板文件

**Bug 描述 / 现象**：AGENTS.md 维护规范引用 `Codex-template.md`，实际文件为 `CLAUDE-template.md`（文件不存在）。

**根本原因**：两份入口文档各自维护模板列表时失同步。

**解决方案**：统一为 `CLAUDE-template.md`，并精简两份入口文档、声明同步维护。

**改动细节**：
- `AGENTS.md` — 修正模板引用

### 2. 归档文件未归档，AI 会误当现行规则

**Bug 描述 / 现象**：`common/ai-coding-rulesystem.md`（标注归档 v1.0.0）与 `common/errors/`（冻结）仍留在 `common/` 下，扫描时会误导 AI 加载过时规则；README 版本号停留在 v3.1.0 与 main.md v3.2.2 不一致。

**根本原因**：归档没有物理移动；多份文档版本号各写各的。

**解决方案**：移入 `archive/` 并标注 NEVER 加载；入口文档版本号统一。

**改动细节**：
- `archive/ai-coding-rulesystem.md` — 由 `common/` 移入
