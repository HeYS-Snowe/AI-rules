## 功能更新

### 意引补全与引语记录（§一.24）

**如何使用**：用户说出凝练、疑似化用经典而未给出原句的话时，AI 自动补全原句与出处（一句话带过不打断主线），并把「原句↔描述」映射记入 `OrganizationAndUser.md` §6.7。用户无需下指令，机制始终生效。

**五机制**：
1. **识别**——信号：文白夹杂、对仗/对称结构、异常凝练、名句式情绪张力、经典母题（旷达/惜时/离别/抱负/自省…）、化用典故；凡有公认原文与出处的固定表达皆算（诗/词/文/曲/谚语/成语典故/名言/歌词/台词）；普通技术表述与日常口语 NEVER 硬凑
2. **补全**——最贴合的原句+出处；出处拿不准明说"可能"，NEVER 编造（不给优于给错）
3. **记录**——映射即时记入 §6.7，一对多/多对多=多行，NEVER 只记其一
4. **反向对齐**——AI 自然引用时优先用库内已有句；新引入附出处并入库；NEVER 为入库硬塞
5. **温和校正**——用户原句与通行版本出入只纠影响理解的偏差、一次带过，轻微异文不纠

**利弊分析**：
- 利：用户"意到句不到"的时刻被接住；映射库累积为表达资产与跨会话共同语言
- 弊 / 权衡：识别靠语义信号仍有漏报/硬凑风险——靠 §6.7 校准样例与"NEVER 硬凑"禁令压制
