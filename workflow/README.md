# workflow/ — 项目工作流程样本库

> 收录各项目已落地的工作流程文档，提炼自项目实战，供 `.Rules` 规则体系跨项目参考。

---

## 定位

`common/core/workflow.md` 是**通用开发流程模板**（抽象方法论）；
本目录收录的是**各项目实战工作手册样本**（具体落地）。

二者互补：

- 模板告诉你"应该有什么流程"
- 样本告诉你"实际项目是怎么做的、踩过什么坑"

## 收录范围

每个项目一个子目录，收录其工作流程的提炼存档：

- 项目结构、构建、归档、发布、版本管理、文档体系、Git 协作等全流程
- 项目特有的实战经验与约定

## 提炼原则

1. **忠实保留** — 方法论、命名规范、命令、字段定义等实质内容原样保留，不丢信息
2. **剥离内链** — 脱离原项目后失效的相对链接改为文字说明（保留指向 `.Rules` 内 SSOT 的绝对路径）
3. **显式标注** — 区分"项目特有细节"与"可复用模式"
4. **经验提炼** — 文档尾部附「可复用经验提炼」小节，把实战中验证过的、可迁移到其他项目的非显而易见经验显式总结

## 目录结构

```
workflow/
├── README.md          # 本文件（用途 + 原则 + 索引）
└── {项目名}/          # 每项目一目录
    └── 工作流程.md
```
